# Manual Documentation

This directory contains the Sphinx project for the user manual.

## Contents

- `requirements.txt`: Python dependencies for building the manual.
- `make.bat`: Windows helper script to run common Sphinx tasks.
- `source/index.md`: Manual home page and table of contents.
- `source/getting-started.md`: Initial manual section.
- `source/conf.py`: Sphinx configuration, including versioning from Git tags.
