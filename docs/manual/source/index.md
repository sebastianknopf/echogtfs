# EchoGTFS Handbuch

EchoGTFS ist eine Datenintegrationsplattform zur Bereitstellung von GTFS-RT-Daten. Basierend auf einem statischen GTFS-Feed können verschiedene Datenquellen angebunden werden, aus denen dann Echtzeitdaten mit den zum statischen GTFS-Feed passenden IDs erzeugt werden können. Es werden **ServiceAlerts**, **TripUpdates** und **VehiclePositions** unterstützt. ServiceAlerts können alternativ zu einer externen Datenquelle auch manuell erfasst und veröffentlicht werden.
